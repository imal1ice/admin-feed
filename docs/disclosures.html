Chain-verified control disclosures

admin-feed · ERC-8241 control disclosures by ownerwatch

A control disclosure states, in a machine-checkable file, exactly who can change a protocol's contracts — every owner, proxy admin, role holder, Safe signer and timelock. ownerwatch drafts it from the chain and disclosure check verifies every claim against on-chain state, so a reader never has to trust the prose. “Records verified” is how many claims the checker settled against the chain with zero mismatches and zero undisclosed powers. Each example is pinned to a block; re-draft at the current block to re-verify.

How it works

Three commands: disclosure draft writes the file from the chain, disclosure check verifies it (and fails CI on any drift), and the ownerwatch GitHub Action emits a live status badge that goes red the moment on-chain control drifts from the disclosure.
