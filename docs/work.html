Open-source tooling and research on who controls EVM protocols: owners, proxy admins, AccessControl roles, Safe signers and timelocks, read from the chain.

Built

  • ownerwatch (MIT, pip install ownerwatch): alerts when an EVM contract's admin surface changes, and a probe that maps who can upgrade, mint, pause or move funds. Reads the governance of Aave, Compound, Uniswap, Lido, Curve, Balancer, Spark, Euler, Morpho, Fluid, Rocket Pool, CoW and others.
  • ERC-8241 disclosure checker: drafts a control disclosure for the ERC-8241 draft standard from chain state, and checks a published one record by record at a pinned block, including control the disclosure leaves out. Worked example on Aave V3.
  • ownerwatch-action: a GitHub Action that fails CI when the admin surface drifts from a committed baseline, or when an ERC-8241 disclosure no longer matches the chain.
  • admin-feed: a live, hourly feed of admin changes on major protocols across Ethereum, Arbitrum, Optimism and Base, with per-protocol counts of control changes and governance executions.
